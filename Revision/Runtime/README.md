The iOS wrapper bundles the sibling EML checkout's original Python evaluator, anatomy, schemas, library, examples and exercise recipes. Xcode stages them at build time. Set the EML_ROOT build setting to use another checkout. Both the catalog and imported JSON are compiled offline through the same entry point. The preview samples at 12 frames per second and carries the phase-level posture, contact and speed diagnostics. Moving loops evaluate each subsequent travel cycle using EML's cycle-aware solver.

Run `bash Revision/Runtime/bootstrap.sh` before the first build. The script pins the interpreter archive and all pure Python wheels by SHA-256. Xcode selects the device or simulator slice. Only recipe data enters the interpreter and its import paths contain only app-bundled code. The runtime uses CPython 3.13.18 and the full Draft 2020-12 validator shipped by jsonschema. [BeeWare distribution](https://github.com/beeware/Python-Apple-support/releases/tag/3.13-b18) · [CPython iOS embedding](https://docs.python.org/3.13/using/ios.html)

The validator uses the Rust extension rpds-py 0.30.0. The three files in Vendor/rpds are compressed builds of its locked PyPI source for iPhone, Apple silicon Simulator and Intel Simulator. Their rebuild script verifies the source archive and links against the same interpreter. Rebuilds require Xcode and a Rust toolchain with the iOS targets. The app includes the upstream licenses. [rpds-py source archive](https://pypi.org/project/rpds-py/0.30.0/)
