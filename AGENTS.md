# Repository guidance

Read [README.md](README.md) for the current Exercise Studio architecture and native build workflow. For Codex Cloud setup, dependency checkouts and portable checks, read [.codex/cloud/README.md](.codex/cloud/README.md). Native renderer and iOS validation require macOS and Xcode.

Blender authoring uses the explicit 5.2.1 LTS environment baseline documented in the Cloud guide; verify startup and affected assets before changing versions. Blender is optional for ordinary source and EML checks.
